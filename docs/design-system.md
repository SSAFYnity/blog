# SSAFYnity 공식 블로그 디자인 시스템

이 문서는 `blog` 저장소 안에서 완결되는 공식 블로그 디자인 기준이다. 외부 작업공간 문서나 공식 홈페이지 저장소를 빌드 의존성으로 사용하지 않는다.

## 제품 역할

| 항목 | 기준 |
| --- | --- |
| 배포 URL | `https://ssafynity.github.io/blog/` |
| 방문자 모드 | Read |
| 주요 목적 | 공지, 활동, 기술, 후기, 회비 기록 탐색과 읽기 |
| 핵심 증거 | 작성일, 카테고리, 본문, 행사 기록, 운영 자료 |

## 디자인 명제

> 축적되는 동문회 기록을 차분하고 정확하게 읽게 한다.

홈도 홍보 랜딩 페이지가 아니라 편집형 아카이브의 입구로 설계한다. 제목, 날짜, 분류, 본문이 장식보다 먼저 보여야 한다.

## 사용 규칙

- 글 제목, 날짜, 설명의 위계를 색상보다 크기와 여백으로 만든다.
- 본문은 최대 `72ch` 안에서 읽히게 한다.
- 카테고리와 상태에만 pill을 사용한다.
- 검색과 정렬은 콘텐츠보다 시각적으로 무거워지지 않게 한다.
- 글 목록은 카드 그리드보다 편집형 목록을 우선한다.
- 본문과 제목을 별도의 큰 카드로 중첩하지 않는다.
- `prefers-reduced-motion`과 키보드 포커스를 기본 지원한다.

## 금지 패턴

- 홈페이지 히어로를 복제한 장식형 블로그 히어로
- 동일한 `아이콘 + 제목 + 설명` 카드 반복
- 장식용 영문 eyebrow와 과도한 badge
- gradient text와 장식용 blur
- 모든 글을 큰 둥근 카드로 감싸는 구성
- 다른 저장소나 상위 작업공간을 참조하는 import와 정적 자산 경로

## 독립성

- 이 저장소만 clone한 상태에서 `/blog` 경로로 설치, 빌드, 배포할 수 있어야 한다.
- 공식 홈페이지의 CSS, 컴포넌트, 문서를 import하지 않는다.
- 공통 브랜드 값의 변경은 이 저장소 안에서 명시적으로 반영하고 검증한다.

## 공통 셸 적용

| 대상 | 구현 기준 |
| --- | --- |
| Header | `76px` 평면형 헤더, 텍스트 내비게이션, 현재 분류 밑줄, 홈페이지 전환 링크 |
| Dropdown | `14px` 패널, 단일 border, 키보드·Escape 지원 |
| Mobile menu | 우측 독립 패널, `44px` 조작 영역, 스크롤 잠금과 복원 |
| Footer | Brand navy 역상 배경, 콘텐츠 분류, 소셜 채널, 홈페이지 전환 링크 |

구현 파일은 `src/components/SiteHeader.astro`, `src/components/SiteFooter.astro`다. 공식 홈페이지 컴포넌트나 스타일을 import하지 않는다.

## 홈 적용

| 영역 | 기준 |
| --- | --- |
| 첫 화면 | 블로그의 역할과 기록 범위를 보여주는 편집형 아카이브 표지 사용 |
| 최신 글 | 표지 바로 다음에 제목·날짜·설명·실제 대표 이미지 사용 |
| 최근 기록 | 카드 그리드 대신 날짜·분류·제목 중심 편집형 목록 사용 |
| 분류 | 카테고리 설명과 실제 글 수를 구분선 목록으로 표시 |
| 참여 | 후기 열람·제출 경로를 본문 흐름 안에서 제공 |
| 공개 기준 | 운영진 관리·후기 확인 기준을 간결한 목록으로 유지 |

구현 파일은 `src/components/HomeHero.astro`, `src/pages/index.astro`다. Hero는 플로팅 카드나 영문 eyebrow 없이 제목, CTA, 기록 범위를 구분선 구조로 표시한다.

Hero는 공홈과 `1180px` 콘텐츠 폭, 제목 스케일, 2열 비율, CTA, `16px` 밝은 브랜드 틴트 패널, 모바일 재배치 규칙을 동일하게 유지하고 기록 범위 데이터만 블로그 역할에 맞게 표시한다.

## 목록·글 상세 적용

| 영역 | 기준 |
| --- | --- |
| 전체 글 | 날짜·분류·제목·설명 중심 편집형 목록 사용 |
| 카테고리 | 검색·연도·정렬과 카테고리별 특수 기능을 유지하고 장식형 표지 제거 |
| 글 상세 | 제목과 메타를 본문과 분리하되 큰 카드로 감싸지 않음 |
| 본문 | 최대 `72ch`, 안정적인 행간, 행사·작성자 정보는 보조 영역에 표시 |

구현 파일은 `src/pages/posts/index.astro`, `src/pages/category/[category].astro`, `src/pages/[...slug].astro`, `src/styles/global.css`다. 기존 글, 카테고리 필터, 후기 확장, 회비 영수증 기능을 유지한다.

## 최종 검증

| 항목 | 결과 |
| --- | --- |
| 정적 페이지 | 76개 빌드 완료 |
| HTML 구조 | 페이지별 `h1`·`main` 1개, 이미지 대체 텍스트·중복 ID·이름 없는 버튼·메타데이터 누락 0건 |
| 반응형 | `1440px`, `768px`, `390px` 대표 화면 가로 오버플로 0 |
| 기능 | 모바일 메뉴, 카테고리 검색·초기화, 404 화면 확인 |
| 소스 검사 | Impeccable 탐지 0건, `git diff --check` 통과 |
| 저장소 검사 | `npm run build` 통과 |

홈의 중첩 랜드마크와 404 제목 구조를 정리하고, 모바일 메뉴 항목의 최소 터치 높이를 `44px`로 통일했다. 공식 홈페이지 저장소의 파일을 참조하거나 공유하지 않는다.
